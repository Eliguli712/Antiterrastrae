# Otodus megalodon — Native stress design R3

Reproducible complete CT geometry and numerical-field colour edition. Build output is published at release `megalodon-native-stress-r3`; lightweight viewer assets are published on `native-stress-r3-data`.

Every source vertex and triangle is preserved in the production 3MF. The field uses archived numerical COMSOL values on the complete legacy surface, registered to native coordinates and interpolated with four neighbours. The separately named `uncompressed` original solver export is not independently verified. No numerical stresses are reconstructed from colour images.

Run `python build_native_stress.py --site https://megalodon-native-stress-eliguli.eliguli712.chatgpt.site`. Native source hashes, all original CT mask voxels, output triangle order, literal vertex coordinates and random numerical interpolation samples are audited. The R2.1 transparent mount remains a reference-fit candidate.
