# Cynthiacetus source models and print project

The original 1:10 Opal anatomy files remain unchanged and separate from the
author-supplied **1:20 PrusaSlicer reference project**:

`Cynthiacetus_Skull_Supports_1-20.3mf`

- Original upload: 2,413,016 bytes.
- SHA-256: `567bc0cd06ecf6075811b826bb3e3d884fa693d0afff38f3836525739483cfd2`.
- Two source objects: 98,812 skull triangles and 55,660 mandible triangles.
- Millimetres; original plate layout; PrusaSlicer 2.7.4.
- The embedded configuration specifies **FFF**, organic supports, three raft
  layers, a 0.25 mm nozzle and 0.10 mm nominal layers. It is a reference project;
  choose the actual printer/material settings before printing.
- The file contains complete anatomy and support-generation settings. It does
  not contain a separate baked support mesh or textures.

The CV includes a separate 1:20 viewer with a **Display support** button. That
view reproduces all 120,915 actual extruded support/interface toolpath segments
generated by the matching PrusaSlicer version, including the raft. Width/height
ribbons visualise the extrusion paths. No anatomy or support path is simplified.
The source anatomy's triangle connectivity is retained exactly; display
coordinates change only by the slicer's 0.675 mm raft lift, a shared translation,
the Z-up to Y-up display rotation, and millimetre-to-metre conversion.

The neutral display finish distinguishes this untextured print project from the
separate, textured 1:10 Opal downloads. It does not add a texture to the source
3MF. The downloadable 3MF is the exact original upload.

## Reproduce the preview

Install PrusaSlicer **2.7.4** from its official release and use its CLI with the
source project. Write generated files outside the checkout:

```bash
prusa-slicer --dont-arrange --threads 2 --post-process '' \
  --export-gcode --output /tmp/cynthiacetus-preview.gcode \
  downloads/cynthiacetus/Cynthiacetus_Skull_Supports_1-20.3mf
python3 scripts/build-print-supports.py --gcode /tmp/cynthiacetus-preview.gcode
```

The generated G-code is used only as preview data; it is not published as a
machine-ready print file and is never sent to a printer. Post-processing hooks
are disabled when slicing. The source project remains unchanged.

The official Linux GTK2 archive used for this export was
`PrusaSlicer-2.7.4+linux-x64-GTK2-202404050940.tar.bz2`, downloaded from
`github.com/prusa3d/PrusaSlicer/releases/tag/version_2.7.4` over verified HTTPS.
Archive SHA-256:
`b0638b371d6ff2938c831d8f8e62c48a69521efd6c9f6dff25c0effa972b20dc`.

Preview hashes, complete triangle/path counts and the source-coordinate
conversion are recorded in `assets/cynthiacetus/print-project-manifest.json`.
Browser checks cover support toggling and camera preservation on both site
layouts and phone widths; geometry checks compare every source triangle and
exported vertex.

## Split downloads and the larger SLA archive

The 44,338,260-byte support display is now stored as three parts smaller than
32 MiB each. `print-project-1-20-supports.parts.json` records every part's size and
SHA-256, plus the complete original file's checksum. The browser verifies each
part and the complete GLB before displaying it. Failed integrity checks expose
the retry control. Geometry and source triangle counts remain unchanged.

The separately uploaded `Cynthiacetus_Separated_SLA_All.zip` has not reached the
execution workspace: the attachment downloader rejects files above 32 MiB and
has no range/remote-split operation. It cannot be split here until its bytes are
available. Split the original wherever it is stored using the provided helper:

```bash
python3 scripts/chunk_file.py split Cynthiacetus_Separated_SLA_All.zip --output sla-parts
```

Supply the resulting `.parts.json` and `.bin` parts, or a readable download URL.
Reassembly preserves every original ZIP byte and checks each part first:

```bash
python3 scripts/chunk_file.py join sla-parts/Cynthiacetus_Separated_SLA_All.parts.json \
  --output Cynthiacetus_Separated_SLA_All.zip
```

The existing FFF reference project and its support preview do not stand in for
the unavailable SLA archive.
